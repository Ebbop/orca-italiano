# Italiano per Orca

Traduzione italiana dell'interfaccia di [Orca](https://github.com/stablyai/orca), come plugin di lingua.
Solo dati: nessun codice viene eseguito.

> Pacchetto **non ufficiale**, fatto dalla community. Non è affiliato né approvato da Stably / Lovecast Inc.

## Installazione

In Orca: **Impostazioni → Plugins**, aggiungi il catalogo community
(`https://github.com/stablyai/orca-community-plugins.git`, ref `main`), installa **Italiano** e abilitalo.
Poi **Impostazioni → Appearance → Language → Italiano**.

## Versioni

La versione del plugin segue quella di Orca a cui la traduzione è allineata (es. `1.4.251`).
Dopo un aggiornamento di Orca le stringhe nuove restano in inglese finché non esce la versione
corrispondente del pacchetto. I testi che Orca protegge (sicurezza, pagina Plugin) restano sempre in inglese.

Segnalazioni e correzioni: apri una issue in questo repository.
